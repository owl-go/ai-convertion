# 页面视觉与交互规范

## 适用范围与来源

任务板页面。颜色/间距来源 web/tokens.css 的 --ink、--surface、--accent、--space、--border；组件来源 index.html 的原生 label/input/button，没有虚构组件库。教学验收视口选 390×844 与 1280×800；它们是本例检查目标，不是生产支持承诺。

## 具体规则

样式复用 tokens.css；新颜色先找同义 token。列表有加载、空、数据、失败状态，失败显示错误与重试入口。提交中禁用按钮；失败保留标题，成功清空并回到标题输入；完成任务显示“已完成”，用文本表达状态。label 关联输入，status 用 aria-live，所有按钮有可读名称、键盘可达且焦点可见；长标题不得遮挡操作。

## 正确例与反例

正确：完成按钮 pending 时 `button.disabled = true`，失败恢复并给出错误。错误：只把按钮涂灰但还能提交，或失败清空标题。正确：状态写“已完成”；错误：只显示绿色点，无其他文字/可访问名称。

## 实际检查

启动 python3 -m app.server，浏览器打开 http://127.0.0.1:8765/；检查空列表→创建→完成→重复/非法输入；断开服务后检查错误、重试与输入保留。两种目标视口检查换行、主操作无遮挡；用 Tab/Enter 操作并核对焦点。保存截图和步骤到具体需求的验证记录。构建与 HTTP 通过不能证明视口、键盘、读屏或对比度已通过；未执行项标未验证。
