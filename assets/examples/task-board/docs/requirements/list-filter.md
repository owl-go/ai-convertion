# 新增列表筛选

状态：已实现；自动检查见本轮演练，基线二选一与完成后刷新已在浏览器验证；失败恢复见扩展条件演练。教学业务选择仅适用于本项目。

## 目标与粒度

同机用户希望默认专注待完成任务，需要时查看全部。已有创建/完成行为见 [tasks](tasks.md)。本次影响页面、公共列表接口和查询，使用简化需求与独立短方案；不含账户、搜索、分页、删除、外部同步。

## 验收

| AC | 给定与操作 | 可观察结果 |
|---|---|---|
| AC-F1-v1 | 已完成/未完成各一项，GET /api/tasks（省略或 include_done=0） | 仅未完成，按 id 升序 |
| AC-F2-v1 | 勾选“显示已完成任务”，include_done=1 | 返回全部且带 done 状态；取消勾选恢复未完成 |
| AC-F3 | include_done 为空、非法值或重复 | 400 {error}，持久化数据不变 |
| AC-F4 | 当前未完成列表中完成一项 | 刷新后该项消失；勾选全部可见，完成幂等 |
| AC-F5 | 空结果、读取失败后重试 | 显示空/错误状态，失败保留筛选条件，可重试；加载中有反馈 |

具体实现方案见 [list-filter](../designs/list-filter.md)。关键语义已由这个教学需求定义，不外推到其他项目。
