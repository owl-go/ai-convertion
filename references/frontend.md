# 前端工程规范选择

前端工程规则描述代码组织与运行边界，UI 规则描述用户看到和操作的行为；同一任务可能需要两者。生成项目规范时使用 [前端模板](../assets/templates/frontend-standard.md)，并读取适用的 [代码基线](code.md)、[架构基线](architecture.md)、[UI 基线](ui.md)。

- 从 package 清单、锁文件、路由、状态管理、网络适配和构建/测试配置识别真实框架与版本；不默认 Vue、React、全局 store 或某一种目录。
- 明确页面/公共组件/业务组件/状态/网络层归属；页面不能绕过已约定网络层，公共组件不能导入业务页。按现有架构具体化，不强行套层。
- 数据只有一个权威来源；定义服务端状态、页面瞬时状态、共享状态分别由谁管理，避免复制与隐式双向同步。
- 实现请求取消/过期响应处理、加载/失败/空/无权限状态；按项目协议映射错误，不在组件散落 URL、凭证或环境判断。
- 真实构建、类型检查、组件/交互测试与 UI 验收分开说明。使用项目设计系统，与 [UI 模板](../assets/templates/ui-standard.md) 互相链接，避免重复定义 token。

规则给出项目路径、正确短例、常见错误与检查入口。没有前端时不生成本文件，入口写明依据。
